# Фото ресторану (карусель)

Сюди кладуться фотографії для каруселі в блоці «Ресторан».

## Правила іменування

Файли мають називатися числами по порядку, без пропусків:

```
1.jpg, 2.jpg, 3.jpg, ...
```

Карусель автоматично визначає кількість фото від 1 до 10 — виводиться рівно стільки, скільки лежить у папці (поки нумерація йде підряд: 1, 2, 3...).

Підтримувані формати (у такому порядку пріоритету): `.jpg`, `.jpeg`, `.png`, `.webp`, `.svg`.

## Як замінити заглушки

Зараз тут лежать тимчасові заглушки `1.svg … 5.svg`.

1. Додайте свої фото як `1.jpg`, `2.jpg`, … 
2. **Видаліть заглушки `*.svg`**, щоб не було мішанини (для кожного номера береться перший знайдений формат — jpg має пріоритет над svg, але краще прибрати зайве).

Рекомендований розмір/пропорції: ~1200×750 (16:10), горизонтальні.
